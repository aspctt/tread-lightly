## [1.1.0] - 2026-09-23

### Added

- Minecraft 1.21.11, 26.1, 26.2 and 26.3 support, with the 26.1 build also covering 26.1.1 and 26.1.2
- Iron and copper chains jingle underfoot and as you brush past them
- The F3 readout has its own entry in the debug options on 1.21.11 and later, `treadlightly:footsteps`, so it can be switched off
- Happy ghasts float silently like other ghasts instead of walking
- A sources jar beside each download

### Changed

- File names end with the loader, like `TreadLightly-1.1.0+26.3-neoforge.jar`
- No config screen on 26.3 until YetAnotherConfigLib has a build that loads there. The mod works without it

### Fixed

- Your own player climbing ladders silently
